# ⚔️ 스타크래프트 부대 — 클로드 코드 에이전트 팩

유닛 8기로 짠 **범용** 서브에이전트 세트입니다. 특정 프로젝트에 매여 있지 않고,
각 유닛이 자기가 들어간 프로젝트를 스스로 파악해서(매니페스트·기존 관례·테스트 명령)
그 프로젝트 방식대로 일합니다.

서브에이전트는 **자기 창을 따로 열어** 일하고 결과만 보고합니다. 그래서 큰 코드베이스를
뒤져도 본진 대화가 지저분해지지 않고, 유닛마다 권한(도구)과 모델을 다르게 줄 수 있습니다.

## 부대 편성

| 유닛 | 파일 | 하는 일 | 코드 수정 | 모델 |
|---|---|---|---|---|
| 🛠️ **SCV** | `scv.md` | 코드 위치·흐름 찾기 (정찰) | ✗ | sonnet |
| 🎈 **오버로드** | `overlord.md` | 구조 파악, 영향 범위, 문서 동기화 | 문서만 | opus |
| 🚀 **캐리어** | `carrier.md` | 새 기능 구현 (테스트·문서까지) | ✓ | opus |
| 💉 **메딕** | `medic.md` | 버그 재현 → 원인 → 최소 수정 | ✓ | opus |
| ⚡ **하이템플러** | `high-templar.md` | 중복·군더더기 정리 (동작은 그대로) | ✓ | opus |
| 🔫 **시즈탱크** | `siege-tank.md` | 변경분 정밀 리뷰, 심각도별 보고 | ✗ | opus |
| 👁️ **옵저버** | `observer.md` | 비밀값·주입·권한 구멍 점검 | ✗ | opus |
| 🏰 **벙커** | `bunker.md` | 올리기 전 체크리스트, 통과/보류 판정 | ✗ | sonnet |

역할을 나눈 이유는 취향이 아니라 **권한**입니다. 보는 유닛(SCV·시즈탱크·옵저버·벙커)에는
쓰기 도구를 아예 주지 않았습니다. 리뷰하다 말고 코드를 고쳐 놓는 일이 없습니다.

## 부르는 법

하고 싶은 말만 하면 클로드가 설명(`description`)을 보고 맞는 유닛을 부릅니다.

```
결제 취소 처리 어디서 하는 거야?      → SCV
장바구니에 쿠폰 적용 기능 만들어줘     → 캐리어
로그인하면 가끔 세션이 풀려           → 메딕
이대로 올려도 될까?                  → 벙커
```

이름을 직접 불러도 됩니다: `시즈탱크로 방금 바꾼 거 리뷰해줘`

## 자주 쓰는 빌드 오더

- **새 기능**: SCV(어디에 붙일지) → 캐리어(구현) → 시즈탱크(리뷰) → 벙커(배포 점검)
- **버그**: 메딕(재현·수정) → 시즈탱크(옆에 터진 곳 없나)
- **대청소**: 오버로드(영향 범위) → 하이템플러(정리) → 벙커
- **처음 보는 코드베이스**: 오버로드(지도) → SCV(관심 있는 기능만 파고들기)
- **인증·업로드·외부 통신을 건드린 날**: 옵저버 → 벙커

## 다른 프로젝트에 가져다 쓰기

```bash
# 한 프로젝트에서만
cp -r .claude/agents /가져갈/프로젝트/.claude/

# 내 모든 프로젝트에서
cp .claude/agents/*.md ~/.claude/agents/
```

`/agents` 명령으로 지금 어떤 유닛이 잡혀 있는지 볼 수 있습니다.

## 유닛 추가하기

`.claude/agents/<이름>.md` 하나면 끝입니다.

```md
---
name: ghost
description: 언제 이 유닛을 부를지. 이 글을 보고 클로드가 고릅니다. 구체적일수록 잘 잡힙니다.
tools: Read, Grep, Glob        # 생략하면 전부 다 씁니다
model: sonnet                  # sonnet(가볍고 빠름) / opus(무겁고 정확) / inherit
---

무엇을, 어떤 순서로 하고, 무엇은 **하지 않는지** 적습니다.
```

쓸 때의 요령 세 가지.

1. **`description`이 반은 먹고 들어갑니다.** 이 글만 보고 클로드가 유닛을 고릅니다. 상황과 말버릇("안 돼요", "올려도 돼?")을 그대로 넣어 두면 잘 잡힙니다.
2. **"하지 않는 일"을 반드시 적습니다.** 유닛이 강해지는 건 할 일이 많아서가 아니라 안 할 일이 분명해서입니다.
3. **보고 형식을 정해 줍니다.** 심각도 표시나 판정 한 줄처럼 결론이 고정되면 결과를 훨씬 빨리 읽습니다.
