# 시공팀 준비물 기준표 — 설비·배관 / AV(영상음향)

현장 오버로드(`overlord-site`)가 캘린더의 오늘 일정을 읽고 이 표에서 준비물을 뽑아냅니다.
**빠진 게 보이면 여기에 한 줄 추가하세요.** 다음부터 그 항목이 자동으로 따라 나옵니다.

---

## 0. 공통 — 일정 종류와 무관하게 매일

**몸에 챙기는 것**
- 안전모(턱끈), 안전화, 안전조끼, 코팅장갑 + 여분, 보안경
- 신분증·출입증, 작업지시서, 차키, 주차 등록 여부
- 휴대폰 보조배터리 (현장 사진은 **작업 전·중·후** 세 장이 기본)

**차에 상시 싣고 다니는 것**
- 줄자(5m·7.5m), 수평계, 유성매직, 커터칼, 연필
- 드라이버 세트, 몽키스패너, 파이프렌치, 펜치·니퍼, 렌치 세트
- 충전드릴 + 비트 세트, **배터리 2개 이상 완충**, 충전기
- 연장릴선(20m, 누전차단기 달린 것), 멀티탭
- 헤드랜턴·손전등, 검전기
- 보양재(비닐·부직포), 마스킹테이프, 빗자루, 쓰레기봉투
- 여분 장갑, 물, 무릎보호대

---

## 1. 설비·배관

### 1-1. 급수·급탕 배관
- **자재**: 배관(PB / PPR / 스테인리스 주름관 / 동관 — *관경·길이 확인 필요*), 이음쇠(엘보·티·소켓·유니온·니플), 볼밸브, 앵글밸브, 후렉시블 호스
- **공구**: 파이프커터, PPR 융착기, 스테인리스 프레스(압착)기, 동관용 토치·용접봉·확관기, 파이프렌치
- **소모품**: 테프론테이프, 헴프 + 페이스트, 사포, 클리너, 배관 클립·행거, 앵커
- **시험**: 수압시험 펌프, 압력게이지, 막음 플러그 — *시험 압력·유지 시간 확인*
- **화기 쓰면**: 소화기, 방화포, 화기작업허가서 (아래 3-2 참조)

### 1-2. 배수·오수 배관
- **자재**: VG1(PVC)관, 이음관, 트랩, 청소구, 통기 부속, 관통 슬리브
- **공구**: PVC 절단기·톱, 사포, **구배 확인용 수평계**(가장 자주 빠뜨립니다)
- **소모품**: PVC 접착제, 우레탄폼, 실리콘·코킹건, **관통부 방화충전재**
- **확인**: 기존 배관 연결 지점, 냄새 역류 대비 임시 막음

### 1-3. 냉난방·공조 (FCU / 실외기 / 냉매)
- **자재**: 냉매동관(1/4·3/8·1/2 — *조합 확인*), 보온재(아마플렉스), 드레인 호스, 실외기 브라켓·앵커·방진패드, 냉매(R32 / R410A — *기종 확인*)
- **공구**: 플레어 공구, 확관기, 벤딩 스프링, **진공펌프**, 매니폴드 게이지, 토크렌치, 질소 + 레귤레이터
- **소모품**: 보온 테이프, 케이블타이, 드레인 구배용 행거
- **확인**: 진공 시간, 드레인 **구배 방향**, 실외기 전원 차단기 용량

### 1-4. 덕트
- **자재**: 아연도 덕트 / 플렉시블 덕트, 디퓨저·그릴, 행거볼트, 앵커, 캔버스
- **공구**: 함석가위, 리벳건, 전동드라이버, 레이저레벨
- **소모품**: 알루미늄테이프, 실란트, 리벳, 방화 실링

### 1-5. 위생기구 설치
- **자재**: 변기·세면기·수전, 앵글밸브, 후렉시블 호스, **변기 개스킷(왁스링)**, 벽 고정 앵커
- **공구**: 몽키, 수평계, 실리콘건, 실리콘 제거칼, 임팩트
- **소모품**: 백색 실리콘, 테프론테이프, 마스킹테이프
- **확인**: 기존 기구 철거·반출 여부, 배수구 중심 치수

### 1-6. 보일러·펌프
- **자재**: 순환펌프, 개스킷, 니플·유니온, 압력계, 절연테이프
- **공구**: 파이프렌치, 검전기, 멀티미터
- **안전**: **차단기 잠금(LOTO) + 표찰**, 전기 결선은 단독 작업 금지

### 1-7. 누수 점검·보수
- **장비**: 청음식 누수탐지기, 열화상카메라, 배관 내시경, 압력 테스트기
- **응급**: 보수밴드, 에폭시 퍼티, 방수테이프, 양동이·걸레·흡습포
- **확인**: 계량기 검침(작업 전후), 아래층 피해 여부 확인 및 사진

### 1-8. 단열·보온
- 보온재(두께 확인), 보온 테이프, 커터, 케이블타이, 결로 방지 마감

## 2. AV — 영상·음향

### 2-1. 스피커 설치
- **자재**: 스피커, 전용 브라켓·행거, 콘크리트 앵커, **낙하방지 안전와이어**(빠뜨리면 안 되는 항목)
- **선재**: 스피커케이블(2.0~4.0sq — *거리 확인*), 스피콘·바나나 단자
- **공구**: 함마드릴, 압착공구, 레이저레벨, 사다리·작업대
- **확인**: 천장 구조(석고 / 콘크리트 / 텍스), 하중, 각도(청중석 조준)

### 2-2. 프로젝터 · 스크린
- **자재**: 프로젝터, 천장 행거킷, 전산볼트, 스크린, 전원·신호 몰딩
- **선재**: 광HDMI(장거리) 또는 HDBaseT 송수신기 + Cat6
- **확인**: 투사 거리·렌즈 시프트 범위, 스크린 하단 높이, 리모컨 건전지
- **장비**: 사다리 / 이동식 작업대, 레이저 거리계

### 2-3. 디스플레이 · LED월
- **자재**: 월마운트, 앵커, 캐비닛·허브카드·컨트롤러(제조사 확인), 전원·데이터 점퍼
- **공구**: 수평계, 임팩트, 몰딩 커터
- **확인**: 콘센트 위치와 여유 회로, 벽체 종류, 픽셀피치·해상도 설정값

### 2-4. 랙 · 앰프 · 믹서 · DSP
- **자재**: 랙, 케이지너트·랙볼트, 앰프, DSP, AVR·UPS, 패치케이블
- **소모품**: 케이블타이·벨크로, **라벨링기**(나중을 위해 반드시), 접지선
- **확인**: 접지(어스), 전원 계통 분리, 랙 발열·환기

### 2-5. 배선 (신설·증설)
- **선재**: Cat6, XLR, 스피커선, 광HDMI, 전원선
- **부속**: RJ45 + 압착기 + **랜테스터**, 캐논 단자 + 인두·납, 몰딩·배관, 피시테이프(낚시줄), 케이블릴
- **확인**: 경로(천장 속·바닥), 관통부, 여유 길이(양단 각 1m)

### 2-6. 무선마이크
- **자재**: 송·수신기, 안테나 분배기, 안테나 케이블, 마이크 커버
- **소모품**: **AA 건전지 다량**(리허설분까지), 여분 마이크 1대
- **확인**: 주파수 스캔(현장 전파 환경), 채널 표기, 거치대·마이크스탠드

### 2-7. 음향 튜닝 · 하울링 잡기
- **장비**: 측정마이크 + RTA, 소음계, 노트북 + **DSP 소프트웨어·드라이버·전용 케이블**, 테스트 음원, 모니터 이어폰
- **확인**: 튜닝 가능한 시간대(예배·행사 없는 시간), 기존 세팅 **백업 파일 먼저 저장**

### 2-8. 카메라 · 송출 (라이브)
- **장비**: 카메라, 삼각대, 스위처, SDI/HDMI 컨버터, 캡처보드, 노트북
- **확인**: **유선 인터넷 회선**(업로드 속도), 송출 키, 여분 배터리·전원어댑터, SD카드
- **소모품**: 케이블 보양 테이프(동선 걸림 방지)

## 3. 조건부 — 일정에 이 단어가 보이면 무조건 추가

### 3-1. 고소 작업 (2m 이상, 천장·행거·스피커·프로젝터)
사다리 또는 이동식 작업대, **안전대 + 죔줄**, 안전모 턱끈 체결, 하부 통제선, 2인 1조

### 3-2. 화기 작업 (용접·토치·그라인더)
**화기작업허가서**, 소화기, 방화포, 화기감시자, **작업 후 30분 잔불 확인**

### 3-3. 타공·코어드릴
코어드릴 + 비트(직경 확인), 물통 또는 집진기, **철근탐지기**, 하부층 통제, 분진 보양, 관통부 마감재

### 3-4. 전원 결선
검전기, 절연장갑, **차단기 잠금(LOTO) + 작업 중 표찰**, 멀티미터, 단독 작업 금지

### 3-5. 예배·행사가 있는 날 / 전날
소음 작업 가능 시간 확인, **리허설 시각에서 역산한 완료 시간**, 임시 대체 장비(예비 마이크·케이블), 원복 확인

### 3-6. 야외 · 우천
방수포, 우비, 누전차단기 달린 릴선, 자재 젖음 대비, 일정 순연 기준

## 4. 서류·행정

작업허가서 / 화기작업허가서 / 출입·주차 등록 / 시공 전·중·후 사진 / 검사 체크시트 / 자재 반입 리스트 / 폐기물 반출 / 작업 완료 서명

## 5. 이 표를 쓰는 규칙

1. **수량과 규격은 지어내지 않습니다.** 관경, 길이, 채널 수, 층수는 일정에 없으면 "확인 필요"로 남깁니다.
2. **안전 항목은 임의로 빼지 않습니다.** 조건이 걸리면 무조건 들어갑니다.
3. 현장이 두 곳 이상이면 **이동 순서대로** 묶고, 겹치는 준비물은 한 번만 적습니다.
4. 부피가 큰 자재·장비는 **전날 밤 차에 싣는 목록**으로, 작은 것·서류·배터리는 **아침에 챙기는 목록**으로 나눕니다.
