# 말씀과 기도

매일 성경 5장 통독, 1시간 기도 타이머, 기도제목 관리, 찬양 악보 정리와 콘티 짜기를 위한 개인경건 웹앱입니다.

## 기능

- **성경읽기**: 창세기 1장부터 요한계시록 22장까지(총 1,189장) 하루 5장씩 총 238일 통독표를 자동 생성합니다. 오늘 읽을 분량을 바로 확인하고 체크할 수 있으며, 전체 목록에서 개별 날짜도 체크/해제할 수 있습니다.
- **기도타이머**: 기본 60분(자유롭게 분 단위 조정 가능)의 기도 타이머입니다. 시작/일시정지/초기화가 가능하고, 완료 시 알림음이 울리며 기도 기록이 남습니다.
- **기도제목**: 기도제목을 적고, 응답 여부를 표시하거나 삭제할 수 있습니다. 전체/기도중/응답됨으로 필터링할 수 있습니다.
- **찬양**: 휴대폰 갤러리에서 악보 사진을 불러와 키(장조 12개·단조 12개)와 빠르기(빠른 찬양/중간/느린 곡)로 정리하고, 그 곡들로 콘티를 짭니다.

### 찬양 · 콘티 자세히

- **갤러리에서 불러오기**: "갤러리에서 악보 불러오기"를 누르면 휴대폰 사진 앱이 열립니다. 여러 장을 한 번에 고를 수 있고, "한 곡으로 묶기"를 켜면 2장짜리 악보가 한 곡의 1·2쪽이 됩니다. 사진은 긴 변 1800px JPEG으로 줄여 담습니다.
- **키별 정리**: 불러온 곡은 바로 정리 화면이 이어서 뜹니다. 키를 누르면 목록이 `C 키 / G 키 / Am 키 …` 식으로 묶여 정리되고, 키 칩으로 걸러 볼 수 있습니다. 아직 안 정한 곡은 "정리 안 됨"으로 모아 한 번에 정리할 수 있습니다.
- **빠르기**: 🔥 빠른 찬양(워십) · 🙌 중간 · 🕯️ 느린 곡으로 나눕니다. BPM을 모르면 "박자 두드리기"로 곡에 맞춰 네 번 이상 두드리면 BPM을 재서 빠르기까지 맞춰 줍니다.
- **콘티 짜기**: 빠른 곡 수와 느린 곡 수를 정하고 "자동으로 콘티 짜기"를 누르면, 빠른 찬양 → 중간 → 느린 곡 순서로 **키가 가까운 곡끼리** 이어 붙입니다. 곡은 ▲▼로 순서를 바꾸고 ✕로 뺄 수 있으며, 앞 곡과 3반음 이상 차이 나면 조옮김을 살펴보라고 알려 줍니다.
- **악보 넘겨보기**: 콘티 순서대로 악보를 전체 화면으로 넘겨 봅니다. 사진을 누르면 확대되고, 보는 동안에는 화면이 꺼지지 않습니다(지원 기기 한정).
- **글로 복사**: 콘티를 `1. 곡 제목 (G, 빠름)` 형식의 글로 복사해 단톡방에 붙여넣을 수 있습니다.

곡 정보와 콘티는 localStorage에, 악보 사진은 IndexedDB에 저장됩니다. 별도 서버나 로그인이 필요 없고, 사진이 밖으로 나가지 않습니다.

모든 데이터는 이 브라우저 안에만 저장되며 별도 서버나 로그인이 필요 없습니다.
백업 글에는 찬양 곡 정보와 콘티까지 담기지만, **악보 사진은 용량이 커서 담기지 않습니다** — 사진은 갤러리에 그대로 있으니 새 기기에서 다시 불러오면 됩니다.

## 사용 방법

`index.html` 파일을 브라우저로 열면 바로 사용할 수 있습니다. 별도 빌드 과정이 없습니다.

## 앱으로 설치하기 (PWA)

manifest.json과 서비스워커(sw.js)가 포함되어 있어 설치형 웹앱(PWA)으로 동작합니다.

- HTTPS(또는 localhost)로 호스팅한 뒤 접속하면 헤더의 "📲 홈 화면에 앱 추가" 버튼(Android/Chrome)이나 브라우저의 설치 메뉴로 홈 화면/바탕화면에 설치할 수 있습니다.
- iOS Safari는 자동 설치 배너가 없으므로 공유 버튼 → "홈 화면에 추가"를 이용하세요.
- 설치 후에는 오프라인에서도 앱 화면과 데이터(localStorage)가 그대로 열립니다.

GitHub Pages 등 정적 호스팅으로 배포하면 됩니다.
