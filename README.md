# 미용실 고객관리 앱

미용실(헤어숍)에서 쓰는 고객 관리 웹앱입니다. 휴대폰 브라우저에서 바로 쓸 수 있고,
홈 화면에 추가하면 앱처럼 동작합니다.

- **고객 정보** — 이름, 연락처, 성별, 생년월일, 태그, 모발/두피 특이사항, 알러지, 메모
- **고객 내역** — 방문일자 · 시술기록(상세 레시피 포함) · 결제금액 · 결제수단 · 담당 디자이너
- **사진** — 방문별 시술 전/후 사진 업로드(여러 장), 확대 보기, 구글폼 첨부 링크 연결
- **구글폼(엑셀) 연동** — 설문 응답 시트를 올리면 **연락처로 기존 고객과 자동 매칭**.
  앞으로 고객이 폼을 새로 작성해도 같은 고객에게 계속 쌓입니다. 같은 파일을 다시 올려도 중복되지 않습니다.
- **핸즈SOS 등 외부 프로그램 연동** — 열 이름과 순서를 그쪽 업로드 양식에 맞춰 저장해 두고 엑셀/CSV로 내보내기
- **대시보드** — 이번 달 매출·방문·신규 고객, 월별 매출, 인기 시술, 생일 고객, 90일 이상 안 오신 고객

## 실행 방법 (설치 없이 http 로 쓰기)

매장 컴퓨터 한 대에서 앱을 켜두고, 같은 와이파이의 휴대폰·태블릿에서 접속하는 방식입니다.
인터넷 서비스 가입이나 매달 내는 돈이 필요 없습니다.

### 0. 프로그램 내려받기 (한 번만)

https://github.com/Meansii/kwak/tree/claude/hair-customer-management-app-8zq57q 접속 →
초록색 **Code** 버튼 → **Download ZIP** → 내려받은 파일 압축 풀기 →
나온 폴더를 `문서` 같은 곳에 옮겨 둡니다. (폴더 위치는 나중에 바꾸지 마세요)

### 1. Node.js 설치 (한 번만)

https://nodejs.org 에서 **LTS** 버전을 내려받아 설치합니다. (다음 → 다음 으로 진행)

### 2. 실행

폴더 안의 파일을 더블클릭하면 됩니다.

- 윈도우: **`실행_윈도우.bat`**
- 맥: **`실행_맥.command`**

처음 한 번만 필요한 파일을 내려받느라 3~5분 걸리고, 그다음부터는 몇 초면 켜집니다.
검은 창이 뜨면서 접속 주소와 **QR 코드**가 나옵니다.

```
────────────────────────────────────────────────────
  💇  미용실 고객관리 앱이 켜졌습니다.
────────────────────────────────────────────────────
  이 컴퓨터에서:  http://localhost:3000
  휴대폰·태블릿에서 (같은 와이파이):
      http://192.168.0.10:3000   (Wi-Fi)
────────────────────────────────────────────────────
```

### 3. 휴대폰에서 접속

- 휴대폰 카메라로 검은 창의 **QR 코드를 찍으면** 바로 열립니다.
- 또는 브라우저 주소창에 `http://192.168.0.10:3000` 처럼 직접 입력합니다. (숫자는 화면에 나온 것으로)
- 열린 뒤 **홈 화면에 추가**해 두면 앱 아이콘처럼 쓸 수 있습니다.
  - 아이폰: 사파리 → 공유 버튼 → *홈 화면에 추가*
  - 안드로이드: 크롬 → 오른쪽 위 점 3개 → *홈 화면에 추가*

### 4. 비밀번호

처음 비밀번호는 **`kwak1234`** 입니다. 접속한 뒤 **설정 → 비밀번호 변경** 에서 꼭 바꿔주세요.
(실행 파일 안의 `kwak1234` 부분을 고쳐 두어도 됩니다. 단, 앱에서 한 번 바꾼 뒤에는 앱에서 바꾼 값이 우선입니다.)

### 알아둘 점

- **검은 창을 닫으면 앱이 꺼집니다.** 영업 중에는 열어두고, 컴퓨터를 끄면 휴대폰에서도 접속되지 않습니다.
- 윈도우에서 처음 실행할 때 *방화벽 허용* 창이 뜨면 **[허용]** 을 눌러야 휴대폰에서 접속됩니다.
  (개인 네트워크만 체크해도 충분합니다.)
- 공유기를 껐다 켜면 컴퓨터의 주소(`192.168.x.x`)가 바뀔 수 있습니다.
  그럴 땐 검은 창에 새로 나온 주소로 접속하면 됩니다. 자주 바뀌면 공유기 설정에서 고정 IP를 지정하세요.
- 자료(고객·방문·사진)는 전부 **매장 컴퓨터의 `data` 폴더 안**에만 저장됩니다. 외부로 나가지 않습니다.

### 개발자용 명령

```bash
npm install
APP_PASSWORD=원하는비밀번호 npm start   # http://localhost:3000
npm test                                # 자동 테스트
```

`.env.example` 을 참고해 포트(`PORT`)나 저장 위치(`DATA_DIR`)를 바꿀 수 있습니다.

### 나중에 인터넷 주소(https://)가 필요해지면

외부에서도 접속하거나 여러 지점에서 함께 쓰려면 클라우드에 올리면 됩니다.
따라 하기 안내는 **[DEPLOY.md](DEPLOY.md)** 에 있습니다. (Render 기준, 월 1만 원 정도)

## 구글폼 연동하는 법

1. 구글 설문지에서 응답 시트를 엽니다 → **파일 → 다운로드 → 쉼표로 구분된 값(.csv)** (또는 .xlsx)
2. 앱에서 **연동 → 구글폼 가져오기** → 파일 올리기
3. 열 연결 화면에서 앱이 열 이름을 보고 자동으로 연결해 둡니다. 틀린 것만 바꿔주세요.
4. 확인 화면에서 각 줄이 **기존 고객 연결 / 신규 고객 / 중복** 중 무엇인지 미리 보고 저장합니다.

`sample/구글폼_응답_예시.csv` 로 미리 연습해 볼 수 있습니다.

**고객 매칭 규칙** (위에서부터 순서대로)

1. 연락처(숫자만 남긴 값)가 같은 고객
2. 이름 + 생년월일이 같은 고객
3. 이름이 같은 고객이 딱 한 명일 때
4. 이름이 같은 고객이 여러 명이면 자동 연결하지 않고 **"연결하지 못한 응답"** 목록에 넣습니다.
   가져오기 화면에서 어느 고객인지 직접 골라주면 됩니다.

이미 가져온 응답은 내용으로 만든 지문(key)을 저장해 두기 때문에, 전체 시트를 매달 통째로 올려도
새로 들어온 응답만 추가됩니다. 잘못 가져왔다면 **가져오기 기록 → 되돌리기** 로 그 회차의 방문 기록을 지울 수 있습니다.

> 참고: 구글폼의 "파일 업로드" 항목은 구글 드라이브 링크로 들어옵니다. 앱은 그 링크를 사진란에 연결해 두며,
> 링크를 열려면 구글 계정 권한이 필요합니다. 매장에 보관할 사진은 고객 상세 화면에서 직접 올리는 편이 안전합니다.

## 핸즈SOS(외부 프로그램) 연동하는 법

핸즈SOS 공개 API 규격은 확인할 수 없어, **엑셀 양식에 맞춘 파일 내보내기** 방식으로 만들었습니다.

1. **연동 → 핸즈SOS 내보내기** 로 들어갑니다.
2. 핸즈SOS의 고객/매출 일괄 업로드(엑셀 가져오기) 화면에 적힌 열 이름을 그대로 **열 이름** 칸에 적고,
   각 칸에 어떤 정보를 넣을지 고른 뒤 **양식 저장**을 누릅니다. (순서 변경 ↑↓, 열 추가/삭제 가능)
3. 다음부터는 **엑셀(.xlsx) 다운로드** 또는 **CSV 다운로드** 를 눌러 받은 파일을 그대로 올리면 됩니다.

고객 목록용 양식과 시술 내역용 양식을 따로 저장할 수 있고, 시술 내역은 기간을 지정해 뽑을 수 있습니다.

나중에 핸즈SOS API 규격을 받으시면 `server/lib/exporter.js` 의 `buildExport()` 가 만들어 주는 데이터를
그대로 HTTP 전송으로 바꾸면 자동 연동이 됩니다.

## 폴더 구조

```
server/
  index.js            서버 시작점, 라우팅 연결, 오류 처리
  db.js               SQLite 스키마 (고객/방문/사진/폼응답/설정)
  auth.js             비밀번호 로그인, 서명 쿠키 세션
  lib/format.js       전화번호·날짜·금액 정규화 (구글폼 값 해석)
  lib/table.js        CSV/XLSX 읽기, CSV/XLSX 쓰기
  lib/importer.js     열 자동 인식, 고객 매칭, 중복 방지, 저장
  lib/exporter.js     내보내기 항목 정의와 데이터 생성
  routes/             customers, visits, photos, imports, exports, misc(통계·설정·백업)
public/
  index.html, css/, js/   화면 (별도 빌드 도구 없이 그냥 동작)
data/                 SQLite DB + 업로드된 사진 (git 에 올라가지 않음)
test/                 자동 테스트
```

## 데이터 보관과 백업

- 모든 자료는 서버의 `data/` 폴더에 있습니다. `data/kwak.db`(DB)와 `data/uploads/`(사진)를 함께 복사해 두면 그대로 백업됩니다.
- 앱 **설정 → 전체 백업 내려받기** 로 고객·방문·사진 목록을 JSON 파일로 받을 수 있습니다.

## 개인정보 관련 주의

고객 이름·연락처·생년월일·사진이 저장되는 앱입니다.

- 처음 실행 후 **비밀번호를 반드시 변경**하세요.
- 매장 밖(인터넷)에서 접속하도록 열어둔다면 **반드시 HTTPS** 를 사용하세요. (예: Caddy, Nginx + Let's Encrypt)
- 고객에게 수집 동의를 받고, 필요 없어진 정보는 고객 삭제 기능으로 지워주세요.
