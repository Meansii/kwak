# 말씀과 기도

매일 성경 5장 통독, 1시간 기도 타이머, 기도제목 관리를 위한 개인경건 웹앱입니다.

## 기능

- **성경읽기**: 창세기 1장부터 요한계시록 22장까지(총 1,189장) 하루 5장씩 총 238일 통독표를 자동 생성합니다. 오늘 읽을 분량을 바로 확인하고 체크할 수 있으며, 전체 목록에서 개별 날짜도 체크/해제할 수 있습니다.
- **기도타이머**: 기본 60분(자유롭게 분 단위 조정 가능)의 기도 타이머입니다. 시작/일시정지/초기화가 가능하고, 완료 시 알림음이 울리며 기도 기록이 남습니다.
- **기도제목**: 기도제목을 적고, 응답 여부를 표시하거나 삭제할 수 있습니다. 전체/기도중/응답됨으로 필터링할 수 있습니다.

모든 데이터는 브라우저의 localStorage에 저장되며 별도 서버나 로그인이 필요 없습니다.

## 사용 방법

`index.html` 파일을 브라우저로 열면 바로 사용할 수 있습니다. 별도 빌드 과정이 없습니다.

GitHub Pages 등으로 배포하면 모바일에서 홈 화면에 추가해 앱처럼 사용할 수 있습니다.
